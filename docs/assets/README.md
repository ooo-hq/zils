# Zils wordmark

These SVGs outline the same **Grenze Gotisch Semibold (600)** lettering used by
[the Zils website](https://github.com/ooo-hq/zils-web/blob/main/components/zils-wordmark.tsx),
including its −0.025 em letter spacing. They require no external font downloads.
`zils-logo-light.svg` uses dark lettering for light backgrounds;
`zils-logo-dark.svg` uses light lettering for dark backgrounds.

The original font is by the Grenze Gotisch Project Authors / Omnibus-Type:
[font source](https://github.com/Omnibus-Type/Grenze-Gotisch).
